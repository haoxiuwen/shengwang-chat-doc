# 数据中心与加速节点

为满足不同业务覆盖区域的部署需求，声网提供多种数据中心和加速节点选择。你可以根据终端用户分布、业务部署区域以及合规要求，选择合适的数据中心和网络加速方案。

目前声网支持以下数据中心和加速节点。

## 数据中心与加速节点概览

### 数据中心

| 类型         | 名称  | 用途 |
| :----------- | :--------- | :--------- |
| 国内数据中心 | 中国              | 即时通讯 IM 免费版、专业版和旗舰版客户所在集群。该数据中心为绝大部分终端用户均在国内的应用提供服务。 |
| 海外数据中心 | 北美、欧洲和东南亚 | 海外客户所在集群。                                       |

### 加速节点

| 类型         | 名称 |
| :----------- | :--- |
| 海外加速节点 | 全球 |

### 数据中心选择与查看

你可以根据终端用户的主要分布区域选择数据中心：

- 如果绝大部分终端用户位于中国大陆，建议选“中国”数据中心。
- 如果绝大部分终端用户位于海外，建议选择海外数据中心。
- 如果终端用户同时分布在国内和海外，且跨国通信频繁，建议在已有数据中心基础上开通海外加速服务。
- 如果你需要专属资源或更高规格的集群服务，可选择国内 VIP 区或联系商务购买相应服务。

在声网控制台创建项目时：
- 国内数据中心默认为 **中国**。若要使用其他数据中心，需要联系商务经理。
- 海外数据中心默认为 **北美**，也可选择 **欧洲** 或 **东南亚**。

## 国内数据中心

### 应用场景

适用于绝大部分终端用户位于国内的应用。

### 集成说明

创建应用时，国内数据中心默认为 **中国**。

集成各端 SDK 时需要根据应用所在的数据中心使用对应的 WebSocket 地址、RESTful API 地址和小程序地址。

| 类别 | 地址                                    | 
| :----------- | :---------------- |
| WebSocket 地址  | `ngi-im-api-wechat.easemob.com`                   |
| RESTful API 地址  | `ngi-a1.easemob.com`                   |
| 微信小程序  | `ngi-im-api-wechat.easemob.com`                   |
| 支付宝小程序   | `ngi-im-api-wechat.easemob.com`                   |

## 海外数据中心

### 应用场景

适用于绝大部分终端用户位于海外的应用。

### 集成说明

集成各端 SDK 时需要根据应用所在的数据中心使用对应的 WebSocket 地址、RESTful API 地址和小程序地址。

#### WebSocket 地址

| 集群名称    | WebSocket 地址                                             |
| :---------- | :--------------------------------------------------------- |
| 东南亚 | `msync-api-61.easemob.com` 或 `msync-api-61.easecdn.com`   |
| 北美   | `msync-api-41.easemob.com` 或 `msync-api-41.easecdn.com`   |
| 欧洲   | `msync-api-71.easemob.com` 或 `msync-api-71.easecdn.com`   |

#### RESTful API 地址

不同海外数据中心的 RESTful API 请求地址如下：

| 集群名称    | RESTful API 请求地址                         |
| :---------- | :------------------------------------------- |
| 东南亚 | `a61.easemob.com` 或 `a61.easecdn.com`       |
| 北美   | `a41.easemob.com` 或 `a41.easecdn.com`       |
| 欧洲   | `a71.easemob.com` 或 `a71.easecdn.com`       |

#### 微信小程序地址

不同海外集群下，微信小程序使用的地址如下：

| 集群名称    | 微信小程序                                                   |
| :---------- | :----------------------------------------------------------- |
| 东南亚 | `im-api-wechat-61.easemob.com` 或 `im-api-wechat-61.easecdn.com` |
| 北美   | `im-api-wechat-41.easemob.com` 或 `im-api-wechat-41.easecdn.com` |
| 欧洲  | `im-api-wechat-71.easemob.com` 或 `im-api-wechat-71.easecdn.com` |

:::tip
根据海外数据隐私保护协议规定，选择东南亚、北美或欧洲后，不可迁移至其他集群。
:::

## 海外加速服务

### 应用场景

适用于部分终端用户位于国内、部分终端用户位于海外，且跨国用户之间需要进行消息通信的场景。

### 节点分布

| 名称         | 节点 |
| :----------- | :--- |
| 海外加速节点 | 全球 |

### 使用说明

声网会根据应用所在数据中心及终端用户分布，为你开通所需的网络加速节点。

加速节点默认带宽为 **1 Mbps**，你可以根据实际流量需求配置更合适的带宽。  

如需开通相关服务，请联系你的商务经理。
