# 数据中心与加速节点

为满足不同业务覆盖区域的部署需求，声网提供多种数据中心和加速节点选择。你可以根据终端用户分布、业务部署区域以及合规要求，选择合适的数据中心和网络加速方案。

## 数据中心

### 概述

声网提供以下数据中心：

| 类型         | 名称  | 用途 |
| :----------- | :--------- | :--------- |
| 国内数据中心 | 中国。              | 即时通讯 IM 免费版、专业版和旗舰版客户所在集群。该数据中心为绝大部分终端用户均在国内的应用提供服务。 |
| 海外数据中心 | 北美、欧洲和东南亚。 | 海外客户所在集群。                                       |

### 数据中心选择与查看

你可以根据终端用户的主要分布区域选择数据中心：

- 如果绝大部分终端用户位于中国大陆，建议选“中国”数据中心。
- 如果绝大部分终端用户位于海外，建议选择海外数据中心。
- 如果终端用户同时分布在国内和海外，且跨国通信频繁，建议在已有数据中心基础上开通海外加速服务。
- 如果你需要专属资源或更高规格的集群服务，可选择国内 VIP 区或联系商务购买相应服务。

在声网控制台创建项目时：
- 国内数据中心默认为 **中国**。若要使用其他数据中心，需要联系商务经理。
- 海外数据中心默认为 **北美**，也可选择 **欧洲** 或 **东南亚**。

### 集成说明

1. 移动端 SDK 连接国内数据中心 **中国**。

2. Web 端和小程序端 SDK 集成需要根据数据中心，填写配置对应的 webSocket 地址。

| 数据中心 | Socket 地址          |
| :--------- | :----- | 
| 中国      |  wss://im-api-c1.chat.rtnsvc.com 或  wss://im-api-c1.chat.realtimemesh.com       |

3. RESTful 接口请求地址如下：

| 数据中心 | RESTful API 请求地址                   |
| :--------- | :----- |
| 中国      | https://c1.chat.rtnsvc.com 或 https://c1.chat.realtimemesh.com   |

4. 微信小程序、支付宝小程序的具体地址如下：

| 数据中心 | 微信小程序      | 支付宝小程序           |
| :--------- | :----- | :----- |
| 中国     | im-api-wechat-c1.chat.rtnsvc.com 或 im-api-wechat-c1.chat.realtimemesh.com | im-api-alipay-c1.chat.rtnsvc.com 或 im-api-alipay-c1.chat.realtimemesh.com   |

## 海外加速服务

### 应用场景

适用于部分终端用户位于国内、部分终端用户位于海外，且跨国用户之间需要进行消息通信的场景。

### 使用说明

声网会根据应用所在数据中心及终端用户分布，为你开通所需的网络加速节点。

加速节点默认带宽为 **1 Mbps**，你可以根据实际流量需求配置更合适的带宽。  

如需开通相关服务，请联系你的商务经理。
