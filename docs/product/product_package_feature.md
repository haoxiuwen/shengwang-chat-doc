# 即时通讯 IM 套餐包功能对比

即时通讯 IM 提供 **免费版**、**专业版** 和 **旗舰版** 三种套餐包，满足不同业务发展阶段的需求。下表详细列出了各版本支持的功能，方便你根据实际业务场景进行选择。

每个预付费套餐包均分为国内数据中心版和海外数据中心版。两者提供的功能一致，但服务价格不同。购买时，请根据项目（VID）所在的数据中心选择对应版本。

:::tip

1. `✓` 表示该版本支持的功能。订阅对应套餐包后，即可直接使用。
2. `*` 表示扩展功能。如需使用，可在声网控制台中付费开通。
3. `——` 表示当前版本不支持，需升级到更高版本。
:::
